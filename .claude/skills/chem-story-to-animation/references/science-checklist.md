# 科學事實檢查清單

動畫裡「出場之後跟實驗有關」的一切都要過這份清單。每個實驗都要有一張事實表(內容 / 依據 / 簡化處),放進審稿頁;審稿人簽核後才算過。

## 通用檢查
- [ ] **原子守恆**:反應前後原子種類與數量不變;不能憑空出現或消失物質。
- [ ] **數量比例**:畫面上的數量要和真實比例合理(例如氧氣只減少一部分,不是全消失)。
- [ ] **因果順序**:先點火才會燃燒、蓋上杯子才會缺氧、滴了酸才變色;時間順序不能顛倒。
- [ ] **時間壓縮**:真實要幾分鐘的過程被壓縮成幾秒,要在字幕或畫面註明或寫在事實表。
- [ ] **簡化處**:畫了什麼、沒畫什麼(例如沒畫水蒸氣),寫進事實表;圖例標「示意」。
- [ ] **安全**:只有大人碰火與熱水;不示範危險做法;安全提醒出現在開頭或結尾。
- [ ] **與故事一致**:`check-sync.mjs` 通過;若科學事實與故事不一致,以科學為準,改故事並提醒使用者(故事是給孩子讀的內容)。
- [ ] **數據有出處**:數字(pH、百分比、溫度)來自教科書或公開資料,並標「依一般教科書整理」或附來源;不確定的標「待對照文獻」。

## 已做過的實驗:事實表
### 蠟燭蓋玻璃杯(fire)
- 蠟(含碳與氫)燃燒:蠟 + 氧 → 二氧化碳 + 水(水蒸氣)。動畫畫了 12 個氧分子,靠近火焰的 3 個各接上一個碳原子(灰球)變成二氧化碳(紅-灰-紅);氧原子守恆。**沒有畫水蒸氣**(簡化,圖例標「示意」)。
- 火熄時還剩 9 個氧分子(75%):密閉杯中氧氣約從 21% 降到約 16% 火就熄,氧氣沒有用完。故事因此寫「氧氣變少了,不夠火繼續燒」,不寫「燒完」。
- 火焰先小後熄,熄滅後燭芯冒煙(未完全燃燒的蠟蒸氣),餘燼慢慢暗掉。
- 玻璃杯要開口朝下才能罩住蠟燭;點火用打火機,由大人操作。
- 時間被壓縮(真實約十多秒到半分鐘,依杯子大小)。

### 紫色高麗菜變色(cabbage)
- 紫高麗菜色素(花青素)是酸鹼指示劑:酸性偏紅粉、近中性紫、鹼性偏藍綠至黃綠;顏色隨品牌與濃度略有差別。
- 醋(約 pH 2.5~3)是酸、小蘇打水(約 pH 8.3)是弱鹼。
- 熱水泡切碎的紫高麗菜:色素溶到水裡,水變紫、菜葉變淡(時間壓縮,實際要幾分鐘);蒸氣是凝結的小水珠。
- 每杯只滴兩滴,新顏色約 2.8 秒從液面往下擴散:真實情況兩滴進一整杯顏色變化較慢也較不明顯,是時間與劑量的壓縮;正式版步驟卡要寫清楚份量。
- 第三杯不加東西,保持紫色(對照組)。
- 滴管與熱水由大人操作;用過的菜汁不要喝(結尾字幕)。
