# 科學事實表:煙火為什麼有那麼多顏色?(fireworks)

場景:`src/anim/scenes/fireworks.js`;腳本:`experiments.json` 的 `fireworks`(storyId fireworks、afterPara 3)。

## 核心概念:焰色反應
| 內容 | 依據 | 動畫怎麼畫 / 簡化 |
|---|---|---|
| 金屬(元素)被火燒、加熱時會發出特定顏色的光 | 焰色反應:高溫讓金屬原子(離子)的電子躍遷到較高能階,回到較低能階時放出特定波長的光;每種元素的能階不同,顏色也不同 | 字幕只說「燒起來會發出○色的光」;不畫電子與能階(孩子版不需要) |
| 鈉(Na):黃色 | 鈉 D 線約 589 nm(黃橙色) | 星的顏色 0xffc400;標籤「鈉 Na → 黃色」 |
| 鍶(Sr):紅色 | 鍶鹽(如碳酸鍶、硝酸鍶)的紅光,SrCl 分子的發光帶約 617~646 nm(紅色);鍶原子譜線約 688 nm(已對照煙火化學文獻與《J. Chem. Educ.》2025 的焰色譜線表) | 0xff1000;標籤「鍶 Sr → 紅色」 |
| 鋇(Ba):綠色 | 鋇鹽的綠光,BaCl 分子的發光帶約 511~533 nm(綠色);另有 Ba⁺ 的藍色譜線(約 455 nm),煙火配方要設法壓低它才綠得純 | 0x20f020;標籤「鋇 Ba → 綠色」 |
| 銅(Cu):藍綠色 | 銅鹽(尤其氯化銅)CuCl 分子的強發光帶約 403~456 nm(藍色),較弱的帶到約 530 nm(藍綠);銅原子譜線約 511、515 nm(綠);不同來源把銅的焰色寫成「藍」或「藍綠」(視 Cu(I) 或 Cu(II)),故事採「藍綠色」 | 0x00bfd0(青綠偏藍);標籤「銅 Cu → 藍綠色」;真實的煙火藍色很難做,動畫取故事的「藍綠色」 |
| 顏色來自放進去的金屬鹽(化合物),不是顏料 | 煙火的「星」是壓成小球的混合物:金屬鹽 + 燃料 + 氧化劑 + 黏著劑 | 動畫畫成一顆一顆發光的星,不畫配方 |
| 紫色可以由紅(鍶)與藍(銅)調出來 | 煙火師傅常混合鍶鹽與銅鹽得到紫色 | 「五彩」步驟裡有一朵紫色,只是示意;字幕只說「調出五顏六色的花朵」 |
| 黃色最亮、鈉的黃光很容易蓋過其他顏色 | 鈉雜質在火焰裡會發出很強的黃光 | 沒有特別畫,不說 |

## 物理:升空與爆開
| 內容 | 依據 | 動畫怎麼畫 / 簡化 |
|---|---|---|
| 火箭拋物線上升、愈來愈慢,到最高點速度為 0 才爆開 | 重力使上升速度每秒減少 g;最高點 v = 0(未計空氣阻力) | `y = y0 + v0·τ − ½·GF·τ²`,`v0 = GF·T`;升空約 2.7 秒;程式 `rocketPos()` |
| 尾跡火花 | 火箭推進藥燃燒,火花被拋在後面並受重力下落 | 26 顆點,位置 = 過去的火箭位置 − ½g'a²,亮度遞減 |
| 星往四面八方飛成球形 | 爆開時每顆星得到向外的初速度(第 4 段:熱氣把小球往四面八方推開) | 300 顆星在球面(費波那契球面)上均勻分布,速度大小 ±10% 的差異 → 一個厚度很薄的球殼 |
| 空氣阻力讓星減速,重力把它往下拉,最後掉落 | 阻力 ∝ 速度:`v = v0·e^(−kt)`;加重力後逐漸趨近終端速度 g/k | 閉式解 `p(a) = P0 + d·v·(1−e^(−ka))/k − (g/k)(a − (1−e^(−ka))/k)·ŷ`,所以任何時間都畫得出來(可拖進度);k = 1.5/s |
| 星燒完會變暗、閃爍後熄滅 | 星的藥劑燒完 | 亮度 ∝ (1 − a/L)^1.35,最後 40% 壽命加上閃爍;每顆星拖兩個較暗的點當作殘影(視覺暫留效果) |
| 爆開瞬間有一閃強光,並照亮地面 | 爆炸與星的光 | 一個加成混合的光球快速淡出;一盞點光源以當下煙火的顏色照亮地面,強度與星的亮度同步 |
| 煙火在遠處、很高;人在安全線後面 | 安全距離;只有專業人員操作 | 煙火在 z = −14(人在 z ≈ 0),前面有低矮山丘擋住發射點,**畫面中沒有任何人點火或操作**;人前面有一條柵欄(安全線) |

## 尺度與時間壓縮(必須標示)
- 遠景比例:1 單位 ≈ 10 公尺(人物區仍是 1 單位 ≈ 0.46 公尺);煙火最高點約 8 單位 ≈ 80 公尺,星球直徑約 10 單位 ≈ 100 公尺(真實的大型煙火直徑約幾十到一百多公尺)。
- 時間加快 1.5 倍(升空真實約 4 秒,動畫約 2.7 秒):`GF = 9.8 / 10 × 1.5² ≈ 2.2` 單位/s²。
- 不畫:光比聲音先到(光速遠大於音速,動畫沒有聲音)、煙火外殼與火藥(看不見,第 4 段說明)、爆開的煙霧。

## 與故事的對照
- 故事第 2 段:「鈉是黃色,鍶是紅色,鋇是綠色,銅是藍綠色」→ 與上表一致,沒有衝突。
- 故事第 3 段「調出五顏六色的花朵」→ 「五彩」步驟。
- 故事沒有說明原子為何發光(焰色反應的原理);字幕刻意不寫,避免超出孩子版的程度。
- 小提醒:故事說的是「金屬(元素)被火燒的時候」。實際上煙火的顏色來自「金屬鹽」(化合物)在高溫下發出的光,說「元素」是簡化,孩子版可以接受;若要更精確可改成「含有這些金屬的化合物」。

## 文獻對照(2026-11-14)
- 鍶、鋇、銅的波長範圍已對照煙火化學文獻(Pyrotechnic colorant 條目)與《J. Chem. Educ.》2025 的焰色譜線表:SrCl 617~646 nm、BaCl 511~533 nm、CuCl 403~456 nm;這些是分子發光帶的近似位置,會隨火焰溫度與氧平衡改變。
