# 科學事實表:廚房找鐵與不鏽鋼(iron)

故事:「鐵:會變壞的好朋友」第 4 段。動畫是「小活動」:拿磁鐵到廚房,試鐵鍋與不鏽鋼湯匙。數據依一般教科書與材料手冊整理(一般化學 / 材料科學教科書:鐵磁性、不鏽鋼與鈍化膜;不查具體文獻頁碼,細節標「待對照文獻」)。

| 動畫裡的內容 | 依據 | 簡化處 |
|---|---|---|
| 鐵鍋(鑄鐵或碳鋼,深灰)被磁鐵吸住 | 鐵(以及鑄鐵、碳鋼)是鐵磁性材料,會被磁鐵吸引;吸力在越近時越大(磁力隨距離快速變小,近似與距離的高次方成反比) | 動畫用「越靠近、加速越大」表示;貼上去的回彈是示意。真實只需不到一秒,動畫放慢到幾秒才看得清楚。磁鐵吸力是互相的,鐵鍋很重不會動,所以只畫磁鐵移動 |
| 鐵鍋有一點點鏽斑 | 鐵碰到氧氣和水會生鏽(故事第 2、3 段);鑄鐵鍋保養不好就會長鏽 | 鏽斑只是貼圖裝飾,位置與數量隨意 |
| 常見的不鏽鋼湯匙(304)吸不住 | 304 不鏽鋼(約 18% 鉻、8% 鎳)是奧氏體(austenitic)結構,在退火狀態幾乎不被磁鐵吸;冷加工(例如沖壓成湯匙)可能產生微弱磁性,所以真實的湯匙有時會被磁鐵「輕輕吸一點點」 | 動畫畫成「完全吸不住」。字幕寫「這支不鏽鋼湯匙吸不住;有的不鏽鋼吸得住,有的吸不住」,避免孩子以為「不鏽鋼一定吸不住」 |
| 有的不鏽鋼吸得住 | 430 等肥粒鐵(ferritic)不鏽鋼含鉻但不含鎳,具磁性,吸得住磁鐵(電磁爐鍋具常用);410 等麻田散鐵(martensitic)不鏽鋼也有磁性 | 動畫沒有另外畫「吸得住的不鏽鋼」,只用字幕說明(動畫補充,故事沒寫)。「吸不住磁鐵」不代表不是金屬;「吸得住」也不代表一定會生鏽(430 一樣有鉻保護膜,只是通常比 304 更容易長鏽斑) |
| 不鏽鋼 = 鐵 + 別的金屬(鉻、鎳) | 不鏽鋼定義:鐵為主,含鉻至少約 10.5%(質量),常再加鎳、鉬等。304 約 18~20% 鉻、8~10.5% 鎳 | 放大圖用 50 顆原子的示意:鐵 36(72%)、鉻 10(20%)、鎳 4(8%),隨機排列(真實是金屬晶格,原子排列、距離、大小不同,且原子數量是億億個等級)。球的大小與間距是示意 |
| 不鏽鋼表面有保護膜,所以不容易生鏽 | 鉻碰到空氣中的氧,會在表面形成一層很薄(約 1~3 奈米)、緻密、透明的氧化鉻為主的鈍化膜,擋住氧氣與水碰到裡面的鐵;膜被刮傷後,碰到氧會自己重新長出來 | 動畫:4 個氧分子(兩顆紅球)落到表面,和鉻反應後用掉(氧原子沒有憑空消失:變成膜的一部分,膜用半透明薄片表示);膜的厚度與實際原子層數都是示意;真實形成只要幾秒到幾分鐘,動畫壓縮成幾秒;沒有畫反應式 |
| 氧分子是兩顆紅球 | 與「蠟燭蓋玻璃杯」一致:氧分子 O₂ = 兩個氧原子 | 球棍風,示意 |
| 不鏽鋼「不容易」生鏽,不是「不會」生鏽 | 保護膜被破壞(例如被鹽、氯離子長時間侵蝕、被鐵屑沾染)還是會長鏽斑 | 字幕寫「不容易生鏽」,與故事用字一致 |
| 磁鐵為馬蹄形、一半紅一半銀 | 玩具磁鐵常見外觀 | 紅與銀只是塗色,不代表南北極;吸鐵時不分哪一極(磁鐵吸引未被磁化的鐵靠的是感應磁性) |

## 因果順序檢查
- 先靠近、才吸住(越近越快);拔下來要用力(一開始拔不動),才換去試湯匙。
- 湯匙:磁鐵貼在握把上磨蹭,什麼也沒發生,拿開後湯匙還在原位(沒有被拖動、沒有被吸起)。
- 放大圖是「為什麼不容易生鏽」的說明,和磁鐵吸不吸沒有因果關係(動畫沒有把兩者連在一起;「吸不住磁鐵」與「不容易生鏽」都是因為成分,但不是彼此的原因)。

## 安全
- 小朋友在大人陪同下玩磁鐵;結尾字幕「磁鐵不要放進嘴巴」(強力磁鐵誤吞很危險,動畫用的是玩具磁鐵)。
- 沒有火、沒有熱水、沒有刀具。

## 人物與場景(非科學,但要合物理)
- 小朋友站在小板凳上才搆得到流理台上方的東西(流理台高度約 0.8 m,小朋友手臂長有限);板凳被流理台擋住,畫面上看不到。
- 磁鐵由小朋友手拿著,手的移動用最小急跳曲線;換手(左 → 右)時磁鐵停在兩手中間。
- 物品出場(鍋、湯匙彈出來)是影片轉場效果;出場之後都放在流理台上不動。
