# 空氣裡有什麼?零食袋裡的氮氣(air)科學事實表

動畫:`src/anim/scenes/air.js`;腳本:`src/data/db/experiments.json` 的 `air`;故事:`air`(第 1~3 段)。
數據依一般教科書整理(乾燥空氣的體積百分比),待使用者或審稿人對照文獻確認。

## 1. 空氣的組成(第 1 步「分成一百份」)
| 內容 | 依據 | 動畫怎麼畫 / 簡化 |
|---|---|---|
| 乾燥空氣體積約 78.08% N2、20.95% O2、0.93% Ar、0.04% CO2(再加極少量氖、氦、甲烷等) | 一般教科書、NOAA/NASA 常用數據 | 取整為 78 / 21 / 1:立方體裡 78 個氮分子(藍,兩顆球)、21 個氧分子(紅,兩顆球)、1 個氬原子(灰,單顆球)。CO2(約 0.04%)與其他氣體併入「剩下的 1」,標籤寫「氬、二氧化碳等 1」,沒有另外畫。 |
| 氣體的體積比 = 分子數比(同溫同壓) | 亞佛加厥定律 | 因此 100 個分子的畫面 = 「分成一百份」。真實一立方公分的空氣約有 2.5×10^19 個分子,這裡只是示意。 |
| 氮、氧是雙原子分子(N2、O2),氬是單原子分子(惰性氣體) | 化學基本事實 | 氮、氧各畫兩顆球(球棍風,與 App 圖鑑畫法一致,藍 #3050f8、紅偏深以免過亮),氬畫一顆球;氬原子半徑(約 0.19 nm,凡得瓦半徑)比氮、氧原子(約 0.15 nm)大一些,畫成約 1.2 倍。 |
| 氬的色:App 圖鑑是淺青色(#80d1e3),使用者指定灰色 | 設計決定 | 動畫用灰色,圖例寫「灰球 = 氬原子」。 |

## 2. 氣體分子的運動(立方體、袋內、開袋後)
| 內容 | 依據 | 簡化 |
|---|---|---|
| 氣體分子不停地做隨機的直線運動(熱運動),碰到容器壁彈性反彈 | 氣體動力論 | 每個分子是等速直線運動 + 碰牆彈性反彈(三角波解析式),方向與速率各自隨機。 |
| 同溫下較輕的分子較快(速率 ∝ 1/√質量) | 氣體動力論(N2 28、O2 32、Ar 40) | 氮 : 氧 : 氬 的速率比取 1 : 0.935 : 0.84。 |
| **簡化 1**:分子之間的碰撞省略 | 為了讓動畫是時間的純函式(可拖動進度) | 真實分子每秒碰撞 10^9 次以上;動畫只畫碰到牆壁、餅乾與袋子。 |
| **簡化 2**:大小放大、速度放慢 | 為了看得見 | 真實室溫 N2 平均速率約 500 m/s、分子直徑約 0.3 nm;圖例標「示意:大小放大、運動放慢」。 |
| 分子在餅乾之間運動 | — | 分子碰到餅乾就被推到餅乾外面(連續的投影),所以繞著餅乾走。 |

## 3. 零食袋裡的氮氣(第 2 步「氮氣墊子」)
| 內容 | 依據 | 簡化 |
|---|---|---|
| 食品包裝常用「氮氣填充」(氣調包裝,MAP):把袋內空氣(含氧氣)排出、改充氮氣,再封口 | 食品包裝常識;氧氣會讓油脂氧化(油耗味)、讓食物變質,氮氣很不活潑、無色無味、安全 | 袋內只畫氮分子。**實際袋內還有極少量氧氣**(充氮包裝殘氧通常只剩百分之幾以下,依產品與包材,約 0.5%~3% 或更低;**待對照文獻/廠商規格**)。動畫把這個簡化寫在腳本的 note 與這份事實表,並用標籤「只畫氮氣 N₂」標示。 |
| 袋內氮氣像枕頭:撐開袋子,餅乾不被壓碎 | 氣體充滿容器、壓力向各方向均勻;袋內只是「微微鼓起」,不是高壓(袋內氣壓只比外面略高) | 用一顆小球壓在袋子上:袋子只微微壓凹(約 0.1 單位),餅乾沒被碰到。球是自由落體(重力 G),落到袋子上有小小的彈跳。 |
| 袋外的氧氣進不去 | 包材(鋁箔多層膜)是阻氧層,密封後氧氣透過率極低 | 8 個氧分子在袋子外面飛,碰到袋子被彈開。標籤寫「氧氣被擋在外面」。**簡化**:真實包材仍有極微量透氣,保存期限有限。 |
| 「趕走氧氣」 | 充氮是把袋內氧氣排出 | 沒有演排氣過程,直接呈現結果(袋內只有氮分子)。 |
| 鋁箔反光 | 外觀 | 用環境反射貼圖做出金屬反光;「透明剖面」是影片手法(把袋子變透明來看裡面)。 |

## 4. 打開袋子(第 3 步)
| 內容 | 依據 | 簡化 |
|---|---|---|
| 開口後袋內氣體往外跑,與房間空氣混合;袋子消氣 | 氣體由高壓往低壓流(袋內略高於外面),並向各方向擴散;最後袋內外壓力相同 | 約 3/4 的氮分子在開口後 3~4 秒內陸續經出口跑出去(出口附近噴流較強、很快減速,之後做隨機熱運動、碰房間牆壁彈回);袋子的鼓起程度與留在袋內的分子比例成正比。**時間壓縮**:真實只要不到一秒。 |
| 分子往外是「亂」的,不是整齊飄走 | 氣體擴散是隨機運動的結果 | 每個分子出口後的方向各自隨機,只有出口處有往外的偏向。 |
| 開袋「嘶」一聲 | 氣體快速流出 | 3D 文字「嘶——」(影片手法)。 |
| 餅乾不會因為開袋被壓碎 | 袋子消氣後薄膜蓋在餅乾上,但外面空氣的壓力本來就和袋內相同 | 袋子消氣後薄膜蓋在餅乾堆上,餅乾仍完整。 |
| **簡化**:開袋後房間裡的空氣(約 78% 也是氮氣)沒有畫出來 | 氮氣本來就是空氣的主要成分 | 跑出去的氮分子在「想一想」步驟淡出,代表混進空氣裡看不見。 |

## 5. 想一想(第 4 步)
- 氮氣無色、無味、無毒,打開袋子看不見也聞不到(所以故事用「想一想」,不是「聞一聞」)。
- 零食袋打開時聞到的味道來自食物本身(油、香料),不是氮氣。
- 注意:不要把頭伸進「充氮」的大型容器或密閉空間(氮氣取代氧氣會讓人缺氧)。零食袋裡的量極少,不會有危險,動畫沒有放這句話,若要加進結尾字幕請另外決定。

## 6. 與故事的對照
- 故事第 3 段「像一個軟軟的枕頭,保護餅乾不被壓碎,也讓食物比較不容易壞掉」與科學一致。
- 故事第 1 段「剩下的一份是氬氣、二氧化碳和其他的氣體」:數字取整(0.93% + 0.04% + 其他約 0.01% ≈ 1%),與科學一致。
- 故事第 2 段「氮氣很安靜,不容易和別的東西起反應」:一致(氮分子 N≡N 三鍵很穩定)。
- 無衝突。
