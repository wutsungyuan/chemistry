# 骨架人偶規格

實作:`reference-impl/anim-proto.js` 的 `makeRig()`。流程:**先骨架 → 再物理 → 最後套外皮**。外皮(方塊)只掛在骨頭上,不參與動作計算;換外皮不用改動作。

## 骨頭(13 根)
骨盆(在髖關節高度)、脊椎、頸(頭掛在頸上),左右各:上臂、前臂、大腿、小腿、腳。
長度(骨架單位):上臂 0.5、前臂 0.5、大腿 0.5、小腿 0.38,踝離地 0.12。目前沒有鎖骨、手腕、手指。
質量比例:頭 8%、骨盆加軀幹 48%、每條手臂 5%、每條腿 16%(用來算重心)。

## 關節與活動範圍
| 關節 | 種類 | 活動範圍 |
|---|---|---|
| 肩 | 球窩;用「仰角 + 運動面 + 軸向旋轉」描述(避免萬向鎖) | 仰角 0~175°、運動面 −60°(橫過身體)~135°、軸向旋轉 −80°~100°;手臂往後伸只在仰角 ≤ 50° 時允許 |
| 手肘 | 單軸鉸鏈 | 只能向前彎 0°~150°;不能反折、不能側彎 |
| 髖 | 球窩 | 屈 120°、伸 20°、外展 45°、旋轉 ±45° |
| 膝 | 單軸鉸鏈 | 只能向後彎 0°~140° |
| 脊椎 | 合成關節 | 前屈 45°、後伸 20°、側彎 ±25°、扭轉 ±40° |
| 頸 | 合成關節 | 前後 ±45°、側彎 ±35°、扭轉 ±70° |
超出範圍會被限制,並累計 `viol.n`(逐格掃描要求為 0)。

## 球窩關節的朝向
`ballQ(side, 仰角, 運動面, 旋轉)`:先在自己的長軸上轉「旋轉」,再把手臂擺到(仰角、運動面)。手臂垂下時方向是 −y;運動面 0° 為前方(+z)、90° 為外側。

## 反向運動(IK)
- `twoBone(L1, L2, 到目標的向量, 極向量, 鉸鏈方向)`:先求手肘(膝)的位置(餘弦定理 + 極向量),再求上段完整朝向(y 軸沿肢體、x 軸 = 鉸鏈軸),最後由朝向反推(仰角、運動面、旋轉)。
- 手臂極向量:朝外下方 `(side×0.7, −1, −0.25)`;腿的極向量:朝前 `(0,0,1)`,鉸鏈方向相反(膝向後彎)。
- 「手肘永遠只往前彎」由鉸鏈軸的方向保證(手肘 x 軸 = −(上段 × 下段),膝 = +)。

## 物理
- 重力 g = 9.8 m/s² ÷ 0.46 m/單位 ≈ 21.3 單位/s²。水滴自由落體 `y = y0 − ½gτ²`;水流是拋物線(出口速度 + 重力)。
- 重心:各節質量加權;伸手時重心前移 → 骨盆後移、脊椎前傾(前傾上限約 16°)把重心拉回兩腳之間(`R.solve` 先擺手、算重心、移骨盆、重擺手)。
- 腳踩地:腳踝固定在地面,腿用 IK,膝只能向前彎;腳掌保持水平(腳的旋轉 = 大腿與小腿旋轉的反轉)。
- 跳躍:蹲下(0.24 s)→ 蹬起(0.07 s)→ 空中拋物線(滯空時間 `2√(2h/g)`)→ 落地緩衝(0.2 s)。
- 手的移動:最小急跳軌跡;兩點之間每段用 `mj(u)`。
- 拿東西:手到位後把物體固定在手上(沒有握力、摩擦、重量計算);放下時用最小急跳慢慢放。

## 動作(都只改關節角度)
- 揮手:肩外展 132° ± 14°(大臂擺動),手肘彎 29°~57° 並比大臂慢約 0.14 週期,身體與頭輕微晃動。
- 歡呼:兩手高舉 150° ± 8°,手肘 21°~49°;小朋友同時跳躍。
- 手舉在胸前:肩仰角 42°、運動面 20°、手肘 100°。
- 看向目標:頸的活動範圍內,pitch 與 yaw 打折(w×0.55 / w×0.8),避免低頭過度。

## 逐格掃描
`window.__proto.sweep()` 每 0.1 秒算一次姿勢,回傳最大關節超限次數、手離目標最遠距離(只計權重 ≥ 0.95 的目標)。目標:超限 0、距離 ≤ 0.2。上次結果:超限 0、最遠 0.16(約 7 公分)。
