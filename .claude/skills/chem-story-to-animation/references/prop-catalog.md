# 道具零件目錄

全部在 `reference-impl/anim-proto.js`,都是程式產生(旋轉曲面 + 材質),沒有外部圖檔。物件圓滑,只有人物是方塊。

| 零件 | 函式 | 做法 | 備註 |
|---|---|---|---|
| 旋轉曲面 | `lathe(點列, 段數)` | `LatheGeometry`;點列 `[半徑, 高]` | 玻璃杯、燒杯、碗、杯座、碟子、蠟燭、滴管都用它 |
| 玻璃材質 | `glassMat(不透明度)` | `MeshPhysicalMaterial`:半透明、粗糙度 0.03、環境反射、clearcoat、雙面、不寫深度 | 不用折射(太吃效能) |
| 反光條 | `streak(...)` | 開口圓柱片 + 漸層貼圖,加成混合 | 讓杯子有「玻璃」的亮線 |
| 玻璃杯 | `tumbler(h)` | 厚底、杯口圓邊(圓環)、反光條;**原點在杯子中心**(翻面時繞中心轉) | 蓋蠟燭要開口朝下 |
| 燒杯 | `beaker(h, rad)` | 圓筒、捲邊杯口、刻度與數字(貼圖)、反光條 | |
| 液體 | `liquid(h, rad)` | 圓柱 + 液面圓盤 + 亮邊;顏色用頂點色;`setState(液位, 舊色, 新色, 進度)` 讓新顏色從液面往下暈開 | 紫 → 粉紅 / 藍綠;水也可用(清 → 紫) |
| 火焰 | `flameMesh(core)` | 水滴形曲面 + 自訂著色(底藍、中心黃白、外緣橘、尖端偏紅)、頂點會擺動、加成混合;每個火焰有自己的 `userData.u`(亮度、擺動、熄滅) | 內外兩層 |
| 蠟燭 | `candle(h, rad)` | 圓柱蠟(頂端微凹、蠟油滴)、燭芯、餘燼、小碟子、火焰、光暈(精靈圖)、會閃動的暖色點光源 | `userData` 有 fo、fi、flame、glow、light、ember、wax |
| 煙 / 蒸氣 | `puffs(n)` | 一團團柔軟精靈圖,往上飄、擴散、變淡 | 蠟燭熄滅的煙、熱水蒸氣 |
| 滴管 | `dropper(len)` | 玻璃管(內有液體)、白色套環、大橡皮頭;`userData.bulbMat`、`colM` 可換色;橡皮頭可擠壓 | 握把 = 長度 × 0.92 處 |
| 水滴 | 球 + 縱向拉長 | 自由落體;落到液面時產生漣漪(環形) | |
| 水壺 | S2 內 `kettle` | 不鏽鋼車製壺身、壺嘴(圓錐柱)、環形把手;縮放 0.65;握把到壺嘴口 `D0 = (−0.819, 0.15)` | 傾斜角 38° 倒水;水流是拋物線上的小球 |
| 玻璃碗 + 菜葉 | S2 內 `bowlG` | 碗(旋轉曲面)、切碎高麗菜(壓扁的二十面體,顏色隨溶出變淡)、液體 | |
| 分子(示意) | 球組成 | 氧分子 = 兩顆紅球;二氧化碳 = 紅-灰-紅;球棍風,和 App 圖鑑畫法一致 | 不用方塊 |
| 3D 標籤 | `label(中, 英, 色)` | 畫布貼圖精靈圖,中英兩張貼圖隨語言切換 | |

## 新增道具的步驟
1. 先寫規格(尺寸、幾何、材質、動態、與人手的握點)。
2. 用 `lathe` 或基本幾何做出來,先單獨看一個畫面。
3. 決定它的「出場」是影片效果(`pop`),出場後的行為是否有科學內容(有就要進事實表)。
4. 握點(手要握哪裡)與可及範圍要算過。
