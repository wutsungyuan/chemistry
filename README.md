# 兒童化學樂園 (Kids Chemistry Park)

Three.js 製作的兒童化學學習網站:元素週期表 → 原子 3D → 分子圖鑑 → 分子實驗室(拖拉組合)→ 反應劇場 → 小測驗與徽章。
介面為繁體中文(可開注音)/English。

    npm install
    npm run dev      # 開發(固定 http://127.0.0.1:5174)
    npm run build    # 輸出到 dist/

擴充內容:編輯 `src/data/elements.js`(元素與趣味知識)、`molecules.js`(分子 3D 座標)、`reactions.js`(反應,需原子守恆)。
